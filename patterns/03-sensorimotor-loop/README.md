# Pattern 03: Sensorimotor Loop & Inhibitory Circuit Breaker (Сьюзан Хёрли)

> *"Мышление не является изолированным процессором между входом и выходом. Разумность возникает только в замкнутой сенсомоторной петле, где действие непрерывно корректируется сопротивлением среды."*  
> — **Сьюзан Хёрли**, *«Сознание в действии» (1998)*

> *"Агенты входят в штопор галлюцинаций, потому что инженеры строят их как разомкнутый сэндвич. Агенту нужен не длинный промпт, а контур торможения по нулевому прогрессу."*  
> — **Дмитрий Ефремов**

---

### Архитектурная проблема
Большинство агентных систем строятся по порочной схеме «классического сэндвича»: `Промпт -> Рассуждение (CoT) -> Вызов инструмента`. При возникновении ошибки агент не имеет прямой связи с сопротивлением среды и пытается заболтать сбой новым текстом, входя в бесконечный штопор повторных вызовов.

### Решение
Модель общих контуров (SCM) Сьюзан Хёрли:
1. Замыкание агента в сенсомоторную петлю: считывание объективного состояния среды (`git diff`, вывод компилятора) перед каждым действием.
2. Сторожевой контур торможения (Inhibitory Circuit Breaker): если агент за 2 итерации подряд не изменил физическое состояние системы (дельта = 0), выполнение мгновенно и принудительно обрывается (`HALT_TRIGGERED`).
