# Pattern 04: Architectural Knowing-How & Layer Boundaries (Гилберт Райл)

> *"Знание-как логически первично по отношению к знанию-что. Регламент не содержит в себе правила собственного применения; попытка свести навык к инструкциям порождает бесконечный регресс правил."*  
> — **Гилберт Райл**, *«Понятие сознания» (1949)*

> *"Нейросети — это кремниевое воплощение райловского 'знания-как'. Их интеллект зашит в распределенные веса диспозиций. Пытаться управлять ими через 20 страниц промптов — классическая категориальная ошибка."*  
> — **Дмитрий Ефремов**

---

### Архитектурная проблема
Инженеры пытаются навязать ИИ архитектурную дисциплину через раздувание промптов (регламенты «знания-что»). Модель читает 20 страниц инструкций и все равно смешивает слои приложения, импортируя инфраструктуру в доменную модель. Правила не исполняют сами себя (парадокс Кэрролла).

### Решение
Глубокие нейросети обладают колоссальным процедурным навыком (*knowing-how*), зашитым в весах латентного пространства. Управлять этим навыком нужно не текстом, а **жесткими синтаксическими барьерами компилятора и линтера**. Доменный слой физически изолируется на уровне сборки (`tsconfig`, `dependency-cruiser`). Любой недопустимый импорт отвергается компилятором до этапа ревью.
